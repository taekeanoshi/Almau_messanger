# Что показать на показе (чек-лист)

Сайт: https://almau-messenger.vercel.app. Зайдите заранее под своим аккаунтом, второй аккаунт — на втором телефоне.

## Порядок показа (3–4 минуты)
1. Главная без входа → «Войти».
2. Главная-сводка: пары на сегодня → «Учёба» → расписание.
3. «Ивенты» → «Отметиться, что иду» → «Найти компанию».
4. «Партнёры» → Summit Seekers → «Записаться» на поход.
5. Анонимный чат на двух устройствах: сообщение доходит без имени.
6. «Админка»: заявка и запись, которые только что сделали.
