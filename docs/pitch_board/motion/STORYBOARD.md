# Pople — ролик 30 с, 1920×1080, 60 fps (раскадровка)

Единая нить: «Не с кем идти? Кому-то тоже» → два аноним-огонька встречаются → Pople: всё в одном месте → анонимный чат → «Иду» и компания → клубы → финал.
Темп 120 BPM (бар = 2 с), сцены по барам: 4 / 6 / 6 / 6 / 4 / 4 с.

| Сц. | Время | Варианты (выбран ★) | Решение |
|---|---|---|---|
| 1 Крючок | 0–4 | а) чёрный экран и слова по буквам; ★б) слова «влетают» из глубины (z) с motion blur, потом два огонька сближаются; в) чат-пузыри без ответа; г) пустой стул-силуэт | «Не с кем идти?» бьёт в камеру, «Кому-то тоже.» вырастает буквами, два огонька сходятся и вспыхивают |
| 2 Pople | 4–10 | а) логотип по центру и текст; б) логотип «выпадает» из вспышки; ★в) логотип из вспышки → уезжает в угол, веер из 3 реальных экранов в 3D, камера облетает; г) сетка плиток | вспышка → логотип → реальные экраны (кабинет, главная, ивенты) + плашки «Расписание · Оценки · Задания · Экзамены» |
| 3 Чат | 10–16 | а) только пузыри; ★б) большая фраза «Ник вместо имени» + панель чата в перспективе, набор текста, «раскрылся»; в) разделённый экран; г) телефон | панель чата с примером диалога из сайта (помечен «пример»), кольцо-вспышка при раскрытии |
| 4 Иду | 16–22 | а) скролл афиши; ★б) афиша в перспективе, курсор нажимает «Иду», затем подсветка «Найти компанию»; в) счётчик; г) карта | настоящий скриншот афиши, курсор, рябь клика, подсветка кнопки |
| 5 Клубы | 22–26 | а) логотипы сеткой; ★б) кольцо логотипов вокруг оси с глубиной резкости + карточка похода Summit Seekers; в) бегущая строка; г) карусель | 5 клубов-партнёров вращаются, вперёд выходит Summit Seekers и запись на поход |
| 6 Финал | 26–30 | а) только URL; ★б) вспышка → Pople крупно, светлая полоса по слову, адрес сайта, финальный читаемый кадр ≥1,5 с; в) QR; г) тизер | «Pople», слоган, almau-messenger.vercel.app |

Звук: музыка (Am–F–C–G), бас, арпеджио, кик/хэты, риз-ры и удары на склейках, SFX на действиях (бьёт текст, пузыри, клик, раскрытие). Голоса нет: диктор записывается своим голосом поверх (музыка оставлена умеренной).
