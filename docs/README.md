## Перед запуском для студентов

1. Railway: подключён Volume с путём `/data` и задан `DB_PATH=/data/almau.db`, иначе база стирается при каждом деплое.
2. Railway Variables: `CORS_ORIGIN=https://almau-messenger.vercel.app`, свой длинный `ADMIN_TOKEN`, ключи Brevo.
3. Назначить первого администратора (README → «Первый администратор»).
4. Удалить демо-аккаунты: «Админка → Демо-данные → Удалить всех демо» и поставить `SEED_DEMO_PEOPLE=0`, иначе они создадутся снова при перезапуске.
5. Railway: тариф Hobby ($5), лимит расходов в Settings → Usage.

## Решения команды на будущее

- Telegram-бот больше не развиваем; нужный из него функционал (подбор собеседника по интересам) переносим на сайт.
- Вуз определяется по корпоративной почте студента. Запускаемся с AlmaU, другие вузы подключаем позже, у каждого вуза будет свой администратор.
- Свой домен (например, pople.kz) ещё не куплен.

## Отложенные доработки

По приоритету, подробно — в истории обсуждения с ИИ-ассистентом.

- **P0:** CI с автотестами в GitHub Actions; резервные копии базы; регистрация только с почтой вуза; окно времени и перемешивание вопросов в экзаменах; мониторинг `/health`.
- **P1:** уведомления (push и почта), напоминания о походах на сайте, замена опроса сервера на SSE, посещаемость списком, экспорт ведомости в CSV и расписания в календарь, страницы партнёров из данных, роль организатора клуба.
- **Позже:** переход с SQLite на PostgreSQL, мультивузовость, свой домен, казахский язык, учебные группы, обмен материалами.
- **Отдел расписания:** может создавать дисциплины, проверка накладок по времени и аудиториям.
