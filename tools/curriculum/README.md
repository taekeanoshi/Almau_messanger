# Учебный план из файлов расписания

`site/data/curriculum.json` собран из Excel-файлов расписания учебного отдела AlmaU (осень 2026-2027).

1. Положить файлы в папку, например `in/` (1, 2, 3 курс и файл МВД; маски имён — в начале `parse_xlsx.py`).
2. `python parse_xlsx.py in` → `raw.json` (листы с датой 2026; пары: дисциплина и преподаватель).
3. `python build_json.py` → `curriculum.json`: специальности по курсам (какой лист к какой специальности — словарь `MAP`),
   очищенные названия дисциплин и преподаватели. Скопировать в `site/data/` и проверить глазами.
4. Нужен `openpyxl` (`pip install openpyxl`). Новые дисциплины сервер досоздаст сам при старте (`bot/curriculum.py`).
