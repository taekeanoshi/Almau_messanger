# Pople — контекст для ИИ-ассистента

Платформа для студентов (запуск с AlmaU, потом другие вузы): учёба + общение + клубы в браузере.
Команда: Дияр, Абулхаир, Хамид. Пользователь общается по-русски, тексты интерфейса и документов — на русском.

## Стек и запуск
- Сервер: Python 3.13, aiohttp, SQLite (`bot/db.py`, миграции колонок в `Database._migrate()`).
  Запуск: `python -m bot.api_server`. Папка называется `bot` исторически, Telegram-бота больше нет.
- Сайт: `site/` — index.html + css/app.css + js/*.js, без фреймворков и сборки; CSP в `site/vercel.json`
  запрещает inline-скрипты. Адрес API — в `<meta name="pople-api">`.
- Хостинг: API на Railway (Volume `/data`, `DB_PATH=/data/almau.db`), сайт на Vercel (Root Directory = site),
  письма через Brevo.
- Тесты: `pytest -q` (все должны быть зелёными). Для интерфейса — проверка в настоящем браузере (Playwright).

## Правила
- Работаем в ветке `main`, коммит и пуш после каждой законченной задачи.
- Схема БД меняется только через `_migrate()`, без потери данных.
- Роли: student, teacher, registrar, organizer (организатор клуба, `web_users.club_id`), admin. Новые эндпоинты проверяют роль.
- Клубная система: `bot/clubs.py` (кабинет организатора, подписки, уведомления), события клубов лежат в таблице
  `hikes` с полем `kind` (`bot/hikes.py`); интерфейс — `site/js/clubs.js`. Демо-вход: `bot/demo_club.py`. Замысел — `docs/rk2/CLUB_SYSTEM.md`.
- Демо-аккаунты (`is_demo=1`) не считаются в публичной статистике; перед запуском их удаляют.
- Учебный план: `site/data/curriculum.json` + `bot/curriculum.py` (каталог дисциплин, авто-запись студента
  по курсу и специальности, оценки ТК1/РК1/ТК2/РК2/Сессия). Пересборка из Excel — `tools/curriculum/`.

## Учёба по курсу (docs/)
- Документы, ссылки, чек-лист запуска, отложенные доработки — `docs/README.md`.
- Курс «Стандарты и принципы проектного управления»: ИИ разрешён только для поиска информации
  и визуализации. Аналитический текст пользователь пишет сам — давать таблицы, схемы, шаблоны и
  вопросы, не писать за него выводы. Не выдумывать цифры и факты.
- Текущая работа: Блок 3 экзаменационного проекта (`docs/block3/`). Осталось: вопросы 1–10 для
  разделов «Оценка достижения целей», «Анализ эффективности», «Lessons Learned» (по одному вопросу),
  затем план абзацев по ответам пользователя.
