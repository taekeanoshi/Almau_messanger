# Pople — контекст для ИИ-ассистента

Платформа для студентов (запуск с AlmaU, потом другие вузы): учёба + общение + клубы в браузере.
Команда: Дияр, Абулхаир, Хамид. Пользователь общается по-русски, тексты интерфейса и документов — на русском.

## Стек и запуск
- Сервер: Python 3.13, aiohttp, SQLite (`bot/db.py`, миграции колонок в `Database._migrate()`).
  Запуск: `python -m bot.api_server`. Папка называется `bot` исторически, Telegram-бота больше нет.
- Сайт: `site/` — index.html + css/app.css + js/*.js, без фреймворков и сборки; CSP в `site/vercel.json`
  запрещает inline-скрипты. Адрес API — в `<meta name="pople-api">`.
- Хостинг: API на Railway (Volume `/data`, `DB_PATH=/data/almau.db`), сайт на Vercel (Root Directory = site),
  письма через Brevo.
- Тесты: `pytest -q` (все должны быть зелёными). Для интерфейса — проверка в настоящем браузере (Playwright).

## Правила
- Работаем в ветке `main`, коммит и пуш после каждой законченной задачи.
- Схема БД меняется только через `_migrate()`, без потери данных.
- Роли: student, teacher, registrar, admin. Новые эндпоинты проверяют роль.
- Демо-аккаунты (`is_demo=1`) не считаются в публичной статистике; перед запуском их удаляют.
